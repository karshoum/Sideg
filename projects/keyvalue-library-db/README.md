# قاعدة بيانات مفتاح-قيمة — مكتبة كتب

تنفيذ بلغة بايثون لقاعدة بيانات **مفتاح-قيمة (Key-Value)** تخزّن بيانات كتب مكتبة،
حيث المفتاح هو رقم الكتاب `Book ID` والقيمة هي بيانات الكتاب (العنوان، المؤلف، التصنيف).

المشروع هو حلّ الواجب الثاني من مقرر Big Data Analytics — Assignment (3)، ويطبّق
المتطلبات العشرة كاملة: إنشاء القاعدة، عرض السجلات، الجلب بالمفتاح، تعديل التصنيف،
وحساب الإحصائيات (إجمالي الكتب، الكتب لكل تصنيف، التصنيفات المتاحة، والتصنيف الأكثر تكراراً).

---

## المتطلبات

- Python 3.8 أو أحدث

لا توجد أي مكتبات خارجية — البرنامج يعمل بمكتبة بايثون القياسية فقط
(`collections.Counter`).

## بنية البيانات

```
KEY        VALUE
---------  ------------------------------------------------------------------
"B001"  ->  {"title": "Hadoop: The Definitive Guide",
             "author": "Tom White",
             "category": "Big Data"}
```

الصنف `KeyValueDB` هو محرك تخزين مفتاح-قيمة مصغّر يوفّر العمليات الأساسية:

| العملية | الدالة | الوصف |
|---|---|---|
| PUT | `put(key, value)` | إضافة سجل أو استبداله |
| GET | `get(key)` | جلب القيمة بالمفتاح |
| UPDATE | `update_field(key, field, value)` | تعديل حقل داخل القيمة |
| DELETE | `delete(key)` | حذف سجل |
| SCAN | `items()` | مسح كامل لكل الأزواج |

## المتطلبات العشرة وأين نُفِّذت

| # | المطلوب | الدالة |
|---|---|---|
| 1 | إنشاء قاعدة بيانات المكتبة | `build_library()` |

| 7 | عدّ إجمالي الكتب | `count_total_books()` |
| 8 | عدّ الكتب لكل تصنيف | `count_books_per_category()` |
| 9 | عرض التصنيفات المتاحة | `display_categories()` |
| 10 | عرض التصنيف الأكثر تكراراً | `display_most_common_category()` |

## ملاحظات

- التخزين في الذاكرة فقط (in-memory): البيانات تُبنى عند كل تشغيل ولا تُحفظ في ملف.
  لجعلها دائمة يكفي حفظ القاموس في ملف JSON عند الإغلاق وقراءته عند البدء.
- قاموس بايثون (`dict`) هو في جوهره بنية مفتاح-قيمة قائمة على جدول التجزئة (hash map)،
  ولهذا استُخدم كمحرك تخزين فعلي داخل `KeyValueDB`.
