                      Sideg - مجموعة مشاريع صغيرة
                            ابدأ من هنا

المشاريع المتوفرة حاليا:

  1) tensorflow-lab      معمل TensorFlow - اعداد بيئة tf_env واول شبكة عصبية
  2) house-price-ann     توقع اسعار المنازل بشبكة عصبية
  3) seminar-11-agents   سيمنار: من النماذج اللغوية الى الوكلاء

لكل مشروع ملفا Word جاهزان:  submission.docx  للتسليم،  explanation.docx  للشرح.

كل مشروع في مجلد مستقل داخل  projects  وله ملف README.md خاص به.

--------------------------------------------------------------------
1) معمل TensorFlow
--------------------------------------------------------------------

اذا كنت تريد معمل TensorFlow (اعداد بيئة tf_env واول شبكة عصبية):

  1) افتح المجلد:      projects  ثم  tensorflow-lab
  2) اقرأ الملف:       README.md   (بداخله الشرح الكامل بالعربية)

  او باختصار شديد:

     - على Windows:
         افتح "Anaconda Prompt" من قائمة ابدأ
         ثم اكتب  cd  ومسافة، واسحب مجلد tensorflow-lab وافلته في النافذة
         ثم اضغط Enter، ثم اكتب:
             setup_windows.bat
         وبعد انتهائه:
             start_jupyter.bat

     - على macOS او Linux:
         افتح Terminal وانتقل الى مجلد tensorflow-lab ثم:
             bash setup_unix.sh
             bash start_jupyter.sh

--------------------------------------------------------------------
2) توقع اسعار المنازل  (house-price-ann)
--------------------------------------------------------------------

  * ملف التسليم:   projects\house-price-ann\submission.docx
  * ملف الشرح  :   projects\house-price-ann\explanation.docx
    افتحهما بالنقر المزدوج (يفتحان في Word او WPS) - لا يحتاجان اي تثبيت.

  * لتشغيل الكود نفسه، من Anaconda Prompt:
        conda activate tf_env
        cd projects\house-price-ann
        pip install -r requirements.txt
        python house_price_ann.py

--------------------------------------------------------------------

  * ملف التسليم:   projects\seminar-11-agents\submission.docx

        python examples\02_simple_agent.py
        python examples\03_multi_agent.py

--------------------------------------------------------------------
ملاحظات مهمة
--------------------------------------------------------------------

* يجب تثبيت Anaconda اولا من:  https://www.anaconda.com/download
  وبعد التثبيت اعد تشغيل الجهاز.

* التثبيت يحتاج اتصال انترنت (حجم مكتبة TensorFlow حوالي 600 ميجابايت)
  وقد يستغرق من 5 الى 15 دقيقة.

* لا تستخدم CMD او PowerShell العادي على ويندوز، استخدم Anaconda Prompt
  والا لن يتعرف الجهاز على الامر conda.

* ملف setup امن لاعادة التشغيل: اذا انقطع الانترنت اعد تشغيله فقط.
